A modern, responsive, and interactive portfolio website showcasing Data Analytics projects, interactive dashboards, SQL case studies, and business intelligence solutions.

🌐 **Live Demo:** [https://kiransundhesha18.github.io/Data-Analyst-Portfolio/](https://kiransundhesha18.github.io/Data-Analyst-Portfolio/)

---

## 🚀 Key Features

- **Interactive KPI & Project Showcases:** Demonstrates hands-on work in Power BI, SQL, Advanced Excel, and Python.
- **Dynamic Theme Switcher:** Smooth toggle between Light and Dark mode with persistent user preference.
- **Skills Matrix:** Categorized overview of analytical capabilities (BI & Visualization, Databases & SQL, Statistical Modeling, and Business Tools).
- **Direct Resume Download:** Built-in PDF download for recruiter convenience.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
- **Automated CI/CD:** Built with Vite and React, automatically deployed to GitHub Pages on every push.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, Lucide Icons, Vanilla CSS
- **Analytics & BI Tools Showcased:** Power BI, DAX, PostgreSQL / MySQL, Excel (VBA, Power Query), Python (Pandas)
- **Deployment:** GitHub Pages & GitHub Actions CI/CD

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kiransundhesha18/Data-Analyst-Portfolio.git
   cd Data-Analyst-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🚀 Deployment to GitHub Pages

### Method 1: Automatic Deployment (Recommended)
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.
1. Go to your repository on GitHub: `https://github.com/kiransundhesha18/Data-Analyst-Portfolio`
2. Navigate to **Settings** > **Pages**
3. Under **Build and deployment > Source**, choose **GitHub Actions**
4. Push any commit to `main`, and GitHub will automatically build and publish your site!

### Method 2: Manual CLI Deployment
```bash
npm run deploy
```
This builds the site and pushes the production bundle directly to the `gh-pages` branch.

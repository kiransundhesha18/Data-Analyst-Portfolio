1. Executive Summary & Purpose

This portfolio is an interactive, production-grade web application engineered to showcase technical data analytics capability to recruiters, hiring managers, and commercial stakeholders.

Unlike conventional web developer portfolios, every component here emphasizes:

  • Commercial Value: Problem statements, revenue uplift, inventory risk management, and unit economics.
  • Analytical Tooling: Power BI (DAX, Star Schema, Power Query ETL), Advanced Excel (XLOOKUP, Dynamic Arrays, Financial Modeling), and Relational SQL.
  • Live In-Browser Simulation: An interactive IPL Auction Moneyball dashboard allowing recruiters to filter, inspect quadrants, and review DAX logic without external BI licenses.

3. WHY These Technologies Were Chosen

Technology Role in Project Why It Was Chosen
React 19 UI Framework Allows modular, reusable components (e.g. ProjectCard) and smooth state changes (theme toggle, metric tab switching).
Vite 8 Build Tool Starts in ~250ms, provides instant Hot Module Replacement (HMR), and builds lightweight, optimized production bundles.
Decoupled Data Layer Data Architecture Allows you to add/edit projects and skills in src/data/ without modifying any React or HTML layout code.
Vanilla CSS Tokens Design System Enables seamless dark/light theme switching, custom glassmorphism, and zero framework bloat.
Lucide React Icon Library Lightweight, crisp SVGs with zero image download delay.

4. WHAT Each Section Does

4.1 Navbar (src/components/Navbar.jsx)

Provides brand recognition ("KIRAN SUNDHESHA - Data Analyst"), smooth anchor navigation to #projects, #skills, #about, #resume, and #contact, a dark/light mode switcher, and a mobile hamburger menu.

4.2 Hero (src/components/Hero.jsx)

Delivers the core value proposition: "Turning Complex Data Into Actionable Business Value." On the right, an interactive SVG trend card lets visitors toggle between YoY Sales & Margin, Retail Supply Chain, and Cohort Retention SQL.

4.3 Projects Showcase (src/components/Projects.jsx & ProjectCard.jsx)

Displays detailed case studies structured under the Context-Action-Result (CAR) format:

  • Problem: Explains the business challenge and financial stakes.
  • Methodology: Details the data pipeline, data modeling, DAX, or SQL queries.
  • Business Impact: Quantified metrics (e.g., +24.6% YoY, 18+ Draft Steals, -35% stockout risk).

4.4 Interactive IPL Moneyball Demo (src/components/InteractiveDemo.jsx)

A live simulator modeled on real 2024 IPL auction data. Recruiters can test franchise slicers (SRH, KKR, CSK, RCB), filter player roles (Batter vs Bowler), switch between a 4-quadrant scatter chart and a data table, and view custom DAX formulas.

4.5 Skills Matrix (src/components/Skills.jsx)

Organizes technical skills into 4 distinct pillars (Power BI, Advanced Excel, SQL, Business Analytics) with color-coded mastery tags: Mastered, Proficient, In Progress.

4.6 Credentials & Resume (src/components/Resume.jsx)

Features a direct "Download Resume (PDF)" button pointing to /resume.pdf and a 1-click "Copy Summary" button formatted for recruiter intake screens.

4.7 Contact & Inquiries (src/components/Contact.jsx)

Contains 1-click clipboard email copying (kiransundhesha56@gmail.com), verified LinkedIn and GitHub links, an immediate availability badge, and a prefilled message composer.

Step 5.4: Updating the Resume PDF

  1. Export your resume from Word/Canva/Google Docs as a PDF.
  2. Name the file resume.pdf.
  3. Copy it into the public/ folder: d:\data-Portfolio\public\resume.pdf.
  4. Also keep a copy as Resume.pdf to prevent 404s on case-sensitive servers.
